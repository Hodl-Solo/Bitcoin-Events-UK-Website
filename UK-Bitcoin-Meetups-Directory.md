# UK Bitcoin Meetups Directory

> This file is the master source for meetup details on bitcoinevents.uk. Edit this file; the website data and map are regenerated automatically.

---

## How to Edit

- Put each meetup under the correct regional heading.
- Use the format: `| Name | Day/Schedule | Venue | Status | Links | Map |`
- Status options: `Active`, `Paused`, `Remove`.
- `Remove` entries are excluded from both the directory and the map.
- Map format is `latitude,longitude`. For groups without a fixed venue, use a sensible town or area centre.
- Links format: `[Website](url)`, `[Twitter](url)`, `[Telegram](url)`, `[Nostr](nostr:npub...)`, etc.
- Plain text such as `Find them on Club Orange` can also be placed in the Links column.
- You only need to maintain the usual schedule and stable details here. Use The Meetup Breakdown and organiser links for the latest individual event dates, cancellations and venue changes.
